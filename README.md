# C++ HTTP Server

A lightweight HTTP server written from scratch in modern C++20 without external web frameworks.

## Features

- TCP socket server
- HTTP/1.1 request parsing
- Router
- Dynamic route parameters
- Query parameter parsing
- GET/POST routing
- Form parsing
- JSON parsing
- Modular architecture

```bash
mkdir build
cd build
cmake ..
